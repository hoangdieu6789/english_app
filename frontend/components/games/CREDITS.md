# Credits for the games

- **Broom Flight** (`broom-scene.ts`) is built upon "The Aviator" by Karim Maaloul
  (Codrops, https://tympanus.net/codrops/?p=26501, https://github.com/yakudoo/TheAviator).
  Licence (https://tympanus.net/codrops/licensing/): free to integrate or build upon in
  personal and commercial projects; not to be republished, redistributed or sold as-is.
  Kept ideas: the rotating cylinder world, low-poly cube clouds, a pilot that eases to its
  target height and tilts, pooled particles. The scene, models, wizard theme and game rules
  are new; no file from the original is copied as-is.
- **three.js** (MIT, https://threejs.org) renders the 3D scene.
- Sound effects are made in code with the Web Audio API (`lib/games/sfx.ts`); the drawings
  (castle, wizard, lantern, tower in `scenery.tsx`) are original SVG.
- The look is a generic wizard theme. No names, logos or art from the Harry Potter books or
  films are used.
