# Animation files

- `lightning-vfx.json`: "Lightning VFX" by Clément Pavageau, from LottieFiles
  (https://lottiefiles.com/free-animation/lightning-vfx-dmRWpkG6Ql), under the Lottie Simple
  License (https://lottiefiles.com/page/license). Modified: numbers rounded to one decimal and
  layer names removed to make the file smaller; each drawing is held for 2 frames
  (the original shows it for 1 frame and leaves the next frame empty, which flickers).
  Colors are set by CSS at runtime.
