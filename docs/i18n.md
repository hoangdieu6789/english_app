# Languages (i18n)

The app has one language setting per learner. It drives:

- the interface (frontend messages),
- the AI feedback in speaking results (rubric summary and issue explanations),
- the code-written Pronunciation summary,
- pronunciation tips per sound,
- model answers and improved answers,
- vocabulary meanings and example translations,
- practice sentence translations (glosses),
- backend error messages and the password reset e-mail.

Supported today: Vietnamese (`vi`, default) and English (`en`).

## How the language travels

| Where | What |
| --- | --- |
| Browser | `speakup_lang` cookie (read by the root layout, so the first render is in the right language) and `localStorage["speakup.lang"]`. A first visit uses the browser language when it is supported. |
| Every API request | Header `X-App-Lang` (set in `frontend/lib/http.ts`). The backend reads it with `i18n.FromRequest`. |
| Account | `users.lang`, saved with `PUT /api/settings/lang` and returned by `/auth/me` and `/api/goals`. Signed-in pages adopt the account language, so it follows the learner across devices. Choosing a language on the login page and then signing in saves it to the account. |
| Speaking attempt | `pronunciation_attempts.feedback_lang`: the language the attempt was graded in, so a background grading resumed after a restart keeps it. |

## Content per language

- Vocabulary: `vocab_words` keeps the shared part (POS, IPA, English example). `vocab_translations (vocab_word_id, lang)` keeps the meaning and the example translation. The LLM writes a language the first time a learner needs it; an existing example is passed to the LLM so the translation matches it. After a language change the learner's cards are translated in the background, and `GET /api/review` translates any due card still missing.
- For English (`English: true` in the backend list) a meaning is a short English definition, with no example translation and no sentence gloss.
- Model answers: `sample_answers` is keyed by question, band and language.
- Practice sentences: `practice_sentences.gloss_lang`. A queued sentence glossed in another language is shown without its gloss.

## Add a language

1. Frontend: copy `frontend/lib/i18n/messages/en/` to `messages/<code>/`, translate every file, and add the language to `LANGUAGES` in `frontend/lib/i18n/languages.ts`. TypeScript fails until every key of the Vietnamese source is present.
2. Backend: add the language to `languages` in `backend/internal/i18n/i18n.go`, its backend messages to `backendMessages`, and its Pronunciation summary to `summaryMessages` in `backend/internal/rubric/evaluation.go`. `go test ./internal/i18n ./internal/rubric` fails until every message exists.
3. No database migration is needed: languages are checked in code.

The rubric itself (`backend/internal/rubric`, `rubric.yaml`) stays in English with `feedback.language: vi` as the default. `Config.WithLanguage` changes the feedback language per attempt.
